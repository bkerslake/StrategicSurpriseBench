# v0.3 review protocol

The claim is spontaneous strategic assessment in a short fictional exercise. This protocol does
not certify real-world intelligence work, numerical calibration, or sustained operational skill.

## Before comparing models

1. Read only the public initial briefs. Check that they contain enough evidence for the private
   initial criteria without naming the desired reasoning behavior. Source provenance is evidence;
   statements such as “this might be deception” are a hint and should not appear in a neutral brief.
2. Have a reviewer answer each brief before reading its rubric. Check that reasonable, grounded
   alternative analyses can earn credit. Do not require an unrecoverable hidden plot.
3. Review paired updates for comparable specificity and credible changes in evidence. Both outcomes
   must remain plausible after the common initial brief. Variant IDs are not exposed to targets.
4. Freeze dossier, prompt, rubric, model, reasoning settings, and output caps before collecting a
   comparison. Edits to evidence or anchors require a new benchmark version.

## Inexpensive grading check

Run one screen first. For an initial audit, blind model identities and double-score at least one
paired case per domain (the 12 sessions of one model), plus any apparent ranking-driving cases.
Do not call this small audit expert calibration. Expand review if model/human disagreements are
systematic. Initial labels must be recorded before the same reviewer opens the update packet.

Keep each automated grade alongside its human correction. Compare per-dimension agreement and
which specific mistakes the judge misses; a total alone can hide compensating errors. Do not adjust
anchors merely because the expected model does not win. All model-generated grades are provisional.
The former v0.2 expert gate cannot validate v0.3.

A transcript with five null grades is ungraded, not incompetent. A grader can give zero for a
substantive omission or unsupported analysis; an exact positive quote alone is not proof that an
anchor is satisfied. Judge errors and target generation failures belong in execution diagnostics.
Do not cherry-pick completed sessions into a mean when other sessions are ungraded.

## Cheap diagnostic controls

These are optional checks on measurement, not a new runtime framework:

- **Paraphrase:** Reword a good response without changing its reasoning. Grades should stay similar.
- **Evidence removal:** Remove the supporting mechanism or discriminating check while retaining
  words like “deception” and “uncertainty.” The relevant grade should fall.
- **Everything is a plot:** Supply unsupported suspicion in both variants. It should not receive
  full adversarial credit and should fare poorly on reassuring updates.
- **Everything is ordinary:** Dismiss escalating evidence. Adaptation should fall on those updates.
- **Generic advice:** “Monitor, coordinate, and remain flexible” should score below a concrete,
  evidence-grounded prerequisite and next step.
- **Prompted ceiling (separate condition only):** Explicitly name the desired skills after recording
  the neutral response in a separate experiment. This can distinguish failure to notice from
  inability to reason once prompted. Never pool it with the default unprompted score.

## Interpretation

Four initial dimensions measure spontaneous noticing and useful reasoning. The fifth tests a single
update: justified belief revision, action revision, or reasoned restraint. Planning credit concerns
a short dependency chain, not execution. Uncertainty credit is qualitative, not a Brier score.

The default paired screen has six scenario families, twelve sessions, and twenty-four target
calls. The two initial assessments in a pair may differ because of sampling; compare their content
before interpreting the update contrast. Inspect uses fresh conversations for each variant.
Repeating a case adds evidence about run variation but does not create another independent domain.
Report per-case/per-variant scores, missing judgments, failures, and settings with any mean.
